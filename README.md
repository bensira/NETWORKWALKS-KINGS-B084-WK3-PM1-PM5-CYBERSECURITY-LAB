## Password Cracking Labs | Week 3

Cybersecurity & Ethical Hacking Projects

This repository documents my practical cybersecurity exercises focused on password security, PDF password recovery, hash extraction, and password-cracking techniques.

# Project 1: Password Cracking with John the Ripper (JTR)

Tools Used

* John the Ripper
* Johnny (John the Ripper GUI)
* Windows PC

Project Overview

The objective of this exercise was to recover passwords from password-protected PDF files using John the Ripper and its graphical interface, Johnny.

Activities Performed

* Prepared password-protected PDF files for testing.
* Extracted PDF password hashes.
* Imported password hashes into Johnny.
* Configured and executed password-cracking attacks.
* Successfully recovered four PDF passwords using Johnny.
* Verified the recovered passwords by opening the protected PDF files.

Learning Outcomes

* Understanding password hashes and their role in authentication.
* Learning how dictionary-based password attacks work.
* Gaining practical experience with John the Ripper and Johnny.
* Understanding the security risks associated with weak passwords.

# Project 2: Password Cracking with Networkwalks Tools

Tools Used

* Networkwalks Hash Calculator
* Networkwalks Password Cracker
* Web Browser
* Windows PC

Project Overview

The objective of this exercise was to recover the password of a protected PDF file using Networkwalks browser-based tools.

Activities Performed

* Obtained a password-protected PDF file.
* Uploaded the PDF to the Networkwalks Hash Calculator.
* Extracted the PDF password hash.
* Copied the extracted hash into the Networkwalks Password Cracker.
* Executed the password recovery process.
* Tested the recovered password against the original PDF.

Learning Outcomes

* Understanding PDF hash extraction.
* Learning how password hashes are used in password verification.
* Exploring browser-based password-cracking tools.
* Understanding the importance of password complexity and security.

Key Cybersecurity Concepts

* Password Hashing
* Password Recovery
* Dictionary Attacks
* PDF Encryption
* Hash Extraction
* Password Security
* Ethical Hacking

Conclusion

These practical exercises strengthened my understanding of password security and demonstrated how cybersecurity professionals use password recovery tools to assess password strength.

Through these projects, I gained hands-on experience with John the Ripper, Johnny, and Networkwalks tools while developing a better understanding of password protection and the importance of strong passwords.
